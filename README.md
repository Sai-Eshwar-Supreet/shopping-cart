# shopping-cart

A simple e-commerce frontend built with **React**.
The application fetches products from an external API and provides core shopping functionality including product browsing and cart management.

## Live Demo

[View live page](https://shopping-cart-rho-lovat.vercel.app)

## Features

This project is a client-side shopping experience with routing and global state management.

- Product listing from external API
- Individual product pages
- Cart management
- Persistent UI state via React Context
- Route-based navigation
- Global state using React Context

## Tech

- Reacts
- JavaScript
- CSS modules

## Run Locally

Clone the repository and install dependencies.

```bash
git clone https://github.com/Sai-Eshwar-Supreet/shopping-cart.git
cd shopping-cart
npm install
npm run dev
```

Open the local server shown in the terminal.

## Deployment

- The project is deployed using Vercel.
- Every push to the main branch automatically triggers a new deployment.
